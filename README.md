# Lawn of the Dead

**A comedy-horror roguelite for the Sega Mega Drive / Genesis, by cosTanSin.**

It's block party night on Maple Lane, and every house ordered pizza. Then a clown
nobody booked honked his horn, and the neighbours stopped being neighbours.
Deliver anyway: four areas, two floors each, a boss on every floor, and whoever's
waiting at the end of the road.

> **This is an alpha (0.1).** Expect rough edges. Saves may be wiped by later versions.

## How to play

- **Emulator:** open the `.md` file in BlastEm, Genesis Plus GX, Ares, or RetroArch
  with the Genesis Plus GX core.
- **Real console:** copy the `.md` file to a flash cart (EverDrive and the like).
  The game saves to battery-backed save RAM.

## Controls

Default layout (Settings has others).

| Button | Action |
|---|---|
| D-pad | Move (the kid throws pizza at his target by himself) |
| A | Throw a firework: breaks things, opens secret walls, hurts everything |
| B | Switch target / take an item / talk |
| C | Dash |
| Start | Pause: map, stats, items, potions, options |
